# 今天也要平安放学

一个简体中文的校园选择小游戏，主角可以选择初三学生或高三学生。

[在线游玩](https://letianhu18-web.github.io/student-school-day/)

## 玩法

- 用方向键、WASD 或拖动屏幕在校园里移动。
- 初始精力为 100，压力为 10；每个选项都会改变这两个数值。
- 压力达到 100、精力降到 0，或触发“被留下”的事件，就会淘汰。
- 所有选项使用相同的边框，选择后显示数值变化。
- 淘汰后才展示对应的公开案例或虚构情境说明。走出校门即可过关。
- 支持声音开关和浏览器中文朗读。

## 本地运行

下载仓库后，用浏览器打开 `index.html` 即可。页面无需安装依赖，也无需构建。

## 内容来源

游戏以提供的网页原型改编，包含 6 个公开通报案例和 20 个虚构日常情境。案例出处在失败页中列出。游戏对话、选项、数值和淘汰结果为创作；公开事件事实以原始通报为准。

页面使用内嵌 HTML、CSS、JavaScript 和 Canvas 绘图，兼容电脑与手机浏览器。
