# 今天也要平安放学

一个简体中文的校园选择小游戏，主角可以选择初三学生或高三学生。

[在线游玩](https://letianhu18-web.github.io/student-school-day/)

## 玩法

- 用方向键、WASD 或拖动屏幕在校园里移动。
- 初始精力为 100，压力为 10；每个选项都会改变这两个数值。
- 压力达到 100、精力降到 0，或触发“被留下”的事件，就会淘汰。
- 所有选项使用相同的边框，选择后显示数值变化。
- 淘汰后才展示对应的案例或改编依据、事实说明和出处链接。走出校门即可过关。
- 支持声音开关和浏览器中文朗读。

## 本地运行

下载仓库后，用浏览器打开 `index.html` 即可。页面无需安装依赖，也无需构建。

## 内容来源

题库共 **100 个情境、300 个选项**，对应 **25 份公开资料**：18 个情境来自真实通报，79 个依据教育文件改编，3 个依据课间活动报道改编。每题都有对应来源，涉及早读、上课、课间、午餐、午休、值日、自习和放学前。

68 题适用于两个年级，17 题只用于初三，15 题只用于高三；初三题库共85题，高三题库共83题。单局随机抽取当天遇到的事件，尽量不重复。

选项使用学生日常表达，例如“本子先交，跟老师说这两题真不会”“先别吵，下课把这事跟家里说”“先喝口水，跟他坐一会儿”。每题3个选项，显示顺序随机。

[完整题目与出处清单](SOURCES.md) · [可读题库源代码](question-bank.js)

`index.html` 内嵌完整题库，可以直接运行；`question-bank.js` 提供相同题库的可读副本，方便查看和修改。页面不额外加载这份副本，修改题库后需要同步到 `index.html` 的内嵌脚本。

真实案例和依据文件、报道编写的虚构情境分别标注。游戏人物、年级、对话、选项、数值与淘汰结果均为创作，不是100起独立新闻。公开事件事实以原始通报为准。行走时的迟到和飞来“批评通知”为附加机制，不计入100题，同样列有改编依据。

页面使用内嵌 HTML、CSS、JavaScript 和 Canvas 绘图，兼容电脑与手机浏览器。
